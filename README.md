# 🧸 Конфигурация для центра детского развития

**1С:Предприятие 8** — конфигурация для автоматизации учёта занятий, оплат и расчёта зарплаты преподавателей в частном центре детского развития.

---

## 📌 О проекте

Центр детского развития — это компания, в которой работает штат педагогов дополнительного образования, ведущих занятия по различным дисциплинам с детьми от 3 до 18 лет.

**Задача:** разработать информационную систему для:
- Учёта занятий и посещаемости
- Учёта поступлений денег от родителей
- Автоматизации расчёта зарплаты преподавателей

**Тип проекта:** учебный (преддипломная практика)

---

## 📋 Основные возможности

### 👨‍👩‍👧‍👦 Учёт учеников и групп

| Объект | Назначение |
|--------|------------|
| **Ученики** | Информация о детях (ФИО, дата рождения, контакты) |
| **Контактные лица** | Родители и представители учеников |
| **Сотрудники** | Преподаватели и административный персонал |
| **Услуги** | Виды занятий (рисование, музыка, спорт, английский и др.) |
| **Кабинеты** | Помещения для проведения занятий |
| **Группы** | Группы детей по возрасту/направлению (ученик может состоять в нескольких группах) |

---

### 📅 График занятий

На каждый месяц формируется график занятий с указанием:
- Занятие (услуга)
- Группа
- Кабинет
- Время (09:00, 10:00, 11:00 и т.д. — занятия всегда 1 час)
- Преподаватель (основной или заменяющий)

**Особенности:**
- Занятие всегда ведёт один педагог
- Возможна замена преподавателя (форс-мажор)
- Отмена занятия с указанием причины (два булевых реквизита: «Оплачивается преподавателю» и «Оплачивается учеником»)
- Проверка занятости кабинета и преподавателя при проведении графика

---

### 💰 Оплата услуг

#### Абонементы
- На месяц / 3 месяца / год и т.д.
- Ученик может посещать все занятия своей группы в указанный период
- Фиксируется документом **«Покупка абонемента»**
- Дата окончания рассчитывается автоматически
- Абонемент считается оплаченным в момент оформления

#### Разовые занятия
- Оплата до начала занятия
- Можно купить заранее несколько занятий
- Фиксируется документом **«Разовое занятие»**

#### Цены
- Устанавливаются документом **«Установка цен»**
- Меняются не чаще раза в месяц (с 1-го числа)
- Цена привязана к услуге (предмету)

---

### 📊 Учёт посещаемости и перерасчёты

#### Отметка посещаемости
- Преподаватель отмечает учеников на каждом занятии
- Отсутствие фиксируется с указанием причины (уважительная/неуважительная)

#### Перерасчёт для абонементов
- Выполняется документом **«Пересчёт средств»**
- Только после окончания действия абонемента
- Возврат за отменённые по вине центра занятия
- Возврат за пропуски по уважительной причине
- **Проверка:** за один абонемент нельзя сделать два пересчёта

#### Особенности разовых занятий
- При отсутствии ученика занятие не списывается
- Возврат денег в полном объёме, если занятие ещё не проведено

---

### 🔄 Переводы и досрочное завершение

#### Досрочное завершение абонемента
- Деньги за прошедшие занятия списываются полностью (с округлением до конца текущего месяца)
- За оставшиеся месяцы возвращается 50%

#### Перевод в другую группу
- Предыдущий абонемент досрочно завершается (по стандартным правилам)
- Оформляется новый абонемент для новой группы

---

### 👨‍🏫 Зарплата преподавателей

| Правило | Описание |
|---------|----------|
| Оплата за проведённые занятия | Сумма не зависит от количества учеников |
| Замена преподавателя | Бонус +20% от оплаты за занятие |
| Отменённое занятие | Оплата только если в причине отмечено «Оплачивается преподавателю» |
| Расчётный период | За указываемый промежуток времени |
| Проверка | За один день не может быть двух документов на одного преподавателя |
| Ставка оплаты | Устанавливается документом **«Установка оплаты преподавателей»** (не чаще раза в месяц, с 1-го числа) |

## 📥 Установка и запуск

1. Скачайте файл конфигурации (`ChildDevelopment.cf` или `ChildDevelopment.dt`)
2. Откройте 1С:Предприятие в режиме **Конфигуратор**
3. Выполните загрузку конфигурации из файла
4. Запустите 1С:Предприятие в режиме **Толстого клиента**
